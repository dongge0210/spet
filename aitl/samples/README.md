# 样本集(回归测试)

## 格式

每个 `*.txt` = **头部元数据 + `---` 分隔线 + 待检测正文**:

```
# expect: 人类            ← 必需:期望档位(子串,断言目标)
# register: 技术笔记       ← 语域。判档的重要上下文
# context: 作者写给自己的实验笔记,含交叉引用和破折号
# source: 会话 / 人造
---
<待检测的原文,原样,可含空行>
```

- **`# expect:`** 是断言目标;其余字段都是**上下文**——判档离不开它
  (技术笔记 / 公文 / 非母语文本会误报,不看语域就会判错)。
- 头部是若干 `# key: value`;**`---` 之后全是正文,不再解析**。
- 同一个 key 写多行即可(会拼接)。

## 跑

```bash
python3 scripts/test_samples.py
```

## 加样本

- **真样本优先**:从真实对话 / 文档里抠。**连上下文一起记**——用户问了什么、这段处在什么场景。
- `# expect:` 先写占位也行(`# expect: 人类`),回头再标。

> 检测器本身也在这套样本的检验之下——档位怎么定可以争,争不赢就改 `expect` 并写明理由。
