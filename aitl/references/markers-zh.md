# 中文 AI 特征词表

来源:去 AIGC 中文词表(github.com/hongcha1101/de-aigc-ch)、多家中文媒体对"AI 味"的分析、以及对比统计数据。用于**逐条标注**与**改写替换**。

## 1. 废话开场(核心标志)

删掉这些空转开头,直接说核心内容。所有"值得……的是""需要……的是"结构都是废话铺垫。

- 值得注意的是,
- 不可否认的是,
- 毋庸置疑的是,
- 众所周知,
- 值得一提的是,
- 首先需要明确的是,
- 说到底,
- 归根结底,
- 从某种程度上来说,
- 从某种意义上说,
- 平心而论,
- 客观来说,
- 坦白说,
- 严格来说,
- 不得不承认的是,
- 需要指出的是,
- 必须强调的是,
- 不容忽视的是,
- 需要说明的是,
- 令人关注的是,

**替换**:直接说内容。"值得注意的是,这个方案有三个优点" → "这个方案有三个优点"。

## 2. 递进链(最高频 AI 句式)

| 句式 | AI 指数 |
|---|---|
| 不只是……更是…… | 极高 |
| 不仅是……更是…… | 极高 |
| 不仅仅是……更重要的是…… | 高 |
| 不只是……同时也是…… | 高 |
| 不仅是……也是…… | 高 |
| 并非……而是…… | 中 |
| 不是……而是…… | 高 |
| 既是……也是……更是……(三重递进) | 极高 |

> **三重递进**:正常人类最多两层"是",AI 爱用到三层。看到连续三个"是"递进,几乎可判为 AI。

**替换**:① 改直接并列("这不只是效率提升,更是工作方式的革命" → "这提升了效率,也改变了工作方式")② 直接删递进关系 ③ 用"而且/同时/还"代替。

## 3. 万能句式

### 时间开头
- 在这个快速发展的时代,
- 在当今这个日新月异的时代,
- 随着科技的不断发展,
- 随着人工智能技术的飞速发展,
- 在数字化浪潮席卷而来的今天,
- 在全球化进程不断加速的当下,
- 在这个充满不确定性的时代,

**替换**:整段删掉,从主语开始写。

### 空洞议论
- 发挥着越来越重要的作用。
- 扮演着不可或缺的角色。
- 具有深远的意义 / 重要的现实意义。
- 值得我们深入思考。
- 引起了广泛的关注。
- 是当务之急 / 刻不容缓。
- 既是挑战也是机遇。
- 是一把双刃剑。
- 是未来发展的必然趋势。
- 正在深刻改变着我们的生活方式。

### "……是……的必然要求"结构
是……的必然选择 / 必由之路 / 客观要求 / 内在需要 / 应有之义 / 根本保障 / 重要前提 / 关键所在。

## 4. 泛化引用(高危:既是 AI 特征又是幻觉)

| 句式 | 风险 | 说明 |
|---|---|---|
| 研究表明…… | 极高 | 最高频幻引句式 |
| 有学者指出…… | 高 | 99% 无具体出处 |
| 据调查显示…… | 极高 | 常伴编造数据 |
| 大量研究表明…… | 极高 | "大量"是幻引遮羞布 |
| 研究证实…… | 高 | 暗示具体实验但实际没有 |
| 国外学者发现…… | 极高 | 利用信息差制造虚假权威 |
| 据权威机构统计…… | 极高 | "权威机构"从不说具体名称 |
| 历史经验表明…… | 中 | 相对安全但仍空洞 |

**黄金法则**:凡是你写不出**作者 + 年份 + 出处**的"引用",全部删掉。

## 5. 冒号 / 破折号滥用

> 对比分析:AI 文本**冒号**频率是人类写作的 **3.2 倍**,**破折号(——)**是 **2.7 倍**。

**冒号滥用**:每段开头用冒号预告——"这意味着:""主要体现在以下几个方面:""原因如下:""一是…二是…三是…"
→ 把冒号后的内容直接写成正常句子。

**破折号滥用**:用破折号做强调——"这是一个——关键的——转折点。"
→ **2000 字文章超过 2 个破折号就要警惕,3 个以上是 AI 特征**;用逗号/句号替换。

## 6. 空洞强调
非常重要 / 极其关键 / 毋庸置疑 / 显而易见 / 毫无疑问 / 不言而喻 / 众所周知 / 不可忽视的是 / 尤为重要的是 / 至关重要 / 不可或缺 / 不可替代 / 举足轻重。

**测试**:把强调词去掉,句子依然成立(或更有力)→ 强调词是多余的。

## 7. 假精确(像有数据,其实是空话)
大量 / 许多 / 众多 / 绝大多数 / 相当一部分 / 显著提升 / 大幅度提高 / 明显改善 / 有效提升 / 极大程度地 / 进一步提升 / 在很大程度上 / 普遍认为 / 大多数人。

**替换**:能写具体数字就写。"这个方案显著提升了效率" → "把处理时间从 3 小时降到 45 分钟"。

## 8. 四字成语三连
齐心协力、攻坚克难、砥砺前行 / 扎实推进、稳步落实、持续优化 / 多措并举、精准发力、务求实效 / 稳中求进、守正创新、行稳致远 …

→ 三个成语排比,只留最贴切的一个。

## 9. 语气软化剂(高频特征)
> AI 文本中**模糊限制语密度是人类文本的 2–4 倍**;**连续两个以上软化词**是显著特征。

可能 / 或许 / 大概 / 某种程度上 / 在一定程度上 / 相对而言 / 比较 / 有些 / 一定的 / 有可能会 / 可以说是 / 似乎 / 看起来 / 往往 / 通常 / 一般说来 / 在某种意义上 / 可以认为 / 大致。

**替换**:要么说确切,要么不说。"这个方案可能会在一定程度上对效率有所提升" → "这个方案能提升效率"(或"这个方案不保证提升效率")。

## 10. AI 尾气(结尾客套)
- 以上是关于……的全部内容。
- 希望以上内容对你有所帮助。
- 如果你有任何问题,欢迎随时交流。
- 总的来说,这是一个值得持续关注的话题。
- 希望本文能为你提供一些参考。
- 感谢你的阅读 / 如果你觉得有用,请点赞收藏。
- 欢迎在评论区留言讨论。

→ 直接结束。文章的结尾是最后一个句号,不需要"售后"。

## 11. 元评论(提醒读者"我在写文章")
正如前文所述 / 如上所述 / 限于篇幅,此处不再展开 / 这里不做过多的赘述 / 我们将在下一节详细分析 / 正如我们前面提到的 / 恕不赘述。

→ 要么把内容写出来,要么别提。说"这里不展开"就是浪费读者时间。

## 12. 被动 / 无主语(AI 不指责任何人)

| 原文 | 改为 |
|---|---|
| 需要被重视 | 团队需要重视 |
| 可以被优化 | 我们可以优化 |
| 应该被关注 | 你应该关注 |
| 被广泛应用 | 开发者正在用 |
| 被认为是 | 我认为是 / 行业认为是 |
| 引起了广泛的关注 | 媒体关注了 |

→ 问自己"谁在做这件事?",把主语写出来。中文不需要被动语态来显得"客观"。

## 13. 语气词对照(中文最容易露馅处)

中文里真正"人味"的是**语气词**——啊/吧/呢/嘛/呗/呀/哈。AI 写中文几乎不用,或用了不对味:

| AI 味 | 人味 |
|---|---|
| 这个方案完全可行。 | 这方案能行吧,先试试呗。 |
| 我认为这是一个值得考虑的问题。 | 这事儿啊,还真得琢磨琢磨。 |
| 你应该早点休息。 | 早点睡啊你,别熬了。 |
| 这是很正常的事情。 | 这不挺正常的嘛。 |

**规律**:AI 的句子干干净净、没有语气、谁都能说;人说话会带"吧/嘛/呗/啊",会省略、会倒装("早点睡啊你")。**一整段一个语气词都没有、句句工整,就是 AI 味。**

## 14. 异常 emoji
人类高频用 心形 / 笑哭 / 点赞 / 眼睛;**AI 异常偏爱 绿框白对勾 / 大脑 / 蓝色小菱形**(以及 勾选框 / 粗勾)。见 [markers-en.md](markers-en.md) 的 emoji 数据。
