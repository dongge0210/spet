# AI 味 vs 人味 对照例

## 例 1(中文,满配 AI 味)

**AI 味:**
> 值得注意的是,在当今这个日新月异的时代,人工智能——这项颠覆性技术——正在深刻改变着我们的生活方式。它不仅仅是一次效率的提升,更是工作方式的革命,也是认知边界的拓展。研究表明,AI 可能在一定程度上显著提升生产力。✅ 首先,它能赋能千行百业;其次,它推动产业升级;最后,它重塑人机关系。总而言之,AI 既是挑战也是机遇,值得我们深入思考。希望以上内容对你有所帮助。

**逐条命中:**

| 片段 | 特征 |
|---|---|
| 值得注意的是,在当今这个日新月异的时代 | 废话开场 + 时间铺垫 |
| 人工智能——这项颠覆性技术——正在 | 长破折号强调 |
| 不仅仅是……更是……也是…… | 三重递进 |
| 研究表明, | 泛化引用 |
| 可能在一定程度上显著提升 | 软化剂堆叠 + 空洞强调 |
| ✅ | 异常 emoji |
| 首先……其次……最后…… | 过渡词规律化 |
| 既是挑战也是机遇 | 空洞议论 |
| 希望以上内容对你有所帮助 | AI 尾气 |

**人味:**
> 我用 AI 写了一次周报,交上去五分钟就被组长认出来了。她问我看出来的,她说两句话:"你从来不用破折号";"你嘴上说'赋能'我会以为你被盗号了。"
>
> 说实话它省时间是真省——以前写周报一小时,现在十分钟初稿、二十分钟改。但它不擅长判断谁该夸谁该甩锅,这活儿还得自己来。

差别:有具体的人、对话、数字(一小时→十分钟)、观点和吐槽;句子长短不齐;全篇无 ✅、无"研究表明"。

## 例 2(中文,阅读主题)

**AI 味:**
> 在当今这个信息爆炸的时代,阅读——这项古老而珍贵的习惯——正在面临着前所未有的挑战。它不仅是一种获取知识的方式,更是一种心灵的修行,也是对抗浮躁的武器。✅ 首先,阅读能够拓展视野;其次,它能够沉淀思想;最后,它能提升表达。总而言之,阅读既是挑战也是机遇,值得我们每个人深入思考。

**人味:**
> 我妈昨天问我:"你上回看完一整本书,是什么时候?"
> 我想了半天,是三月那本《献给阿尔吉侬的花束》。不是因为忙。是因为躺在床上刷短视频太顺手了——手指一划就是下一条;而翻开书,得先在心里下个决心:"接下来二十分钟我什么都不干。"
> 所以与其说年轻人不读书,不如说是能选的东西太多了。

## 例 3(英文)

**AI 味:**
> It's worth noting that this isn't just a tool — it's a paradigm shift. Let's dive in to explore the multifaceted landscape of AI capabilities.

**人味:**
> This tool changes how you write. Here's what it actually does.

命中:`It's worth noting`(废话)+ `isn't just a tool — it's`(负向平行 + 破折号)+ `Let's dive in`(开场套路)+ `multifaceted landscape`(一级 slop 词)。

## 例 4(反例:别误报)

这是一段**技术笔记注释**:

> 06 §2 说「只判第 2 条不够,而且会被骗过去」—— 这句话只有在一个「输出并不比思考长、但用了思考里没有的词」的样本上才判得出真假。

它有**一个破折号**,若用"见到破折号=AI"的粗规则会误报。但它也有:行话简称、交叉引用(06 §1 / 08 §5)、量词活用("一身……词")、精确条件限定("只有……才")。**这说明:必须看整体密度与搭配,单项不判。** 反过来说,如果这类"引号 + 破折号 + 冒号 + 转折连词链"在极短篇幅里**扎堆**,那 AI 味就重了。
